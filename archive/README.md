## §2. 🌟 격언 #118 v3 — ARGUS Signal Adoption 5-Tier Rule 🌟 (신규 정식 정착)

### 2.1 본질

🌟 **"portfolio alpha가 0이거나 현재 엔진에서 흡수되지 않더라도, signal quality가 통계적·구조적·경제적으로 입증되면 해당 signal은 폐기하지 않는다. 채택은 최소 5종으로 분리한다."** 🌟

### 2.2 5-Tier 분리 매트릭스

| Tier | 채택 종류 | 조건 | RULE 29 v2 通過 |
|------|---|---|---|
| 1 | 🌟 **Signal Layer 채택** | forward return 예측력 + hit rate + payoff + 단조성 + 시기 설명력 + 전이 가능성 + 흡수 不可 진단 | ❌ 不요구 |
| 2 | **Regime Tag 채택** | 시장 상태 분류기 | ❌ 不요구 |
| 3 | **Monitoring/Alert 채택** | 경고·감시 | ❌ 不요구 |
| 4 | **Research Registry 채택** | 후속 연구 보존 | ❌ 不요구 |
| 5 | 🔴 **Capital Allocation 채택** | 실제 매매 비중 반영 | ✅ **要 (但 5 Level 단계화 — 격언 #119)** |

### 2.3 Signal Layer Tier 1 채택 6 평가축

1. **단일종목 또는 자산군 forward return 예측력** (Phase A α + t-stat + p-value)
2. **hit rate와 payoff 구조** (양수 비율 + best/worst case 비대칭)
3. **signal strength와 future return 단조성** (dose-response)
4. **시기별 또는 regime별 설명력** (era 분기 + regime 분기 일관성)
5. **다른 자산 또는 다른 구현 방식 전이 가능성**
6. **기존 엔진이 흡수하지 못한 이유의 명확한 진단** (slot 구조 / threshold / DEAD ASSET / Crown 重복 등)

### 2.4 위반 처리

## §3. 🌟 격언 #119 v1 — ARGUS Capital Reflection Rule 5 Level 🌟 (신규 정식 정착)

### 3.1 본질

🌟 **"Signal quality가 입증되고 portfolio alpha가 음수가 아니면, 해당 signal은 실제 비중·매매에 완전히 배제하지 않는다. 단, 반영 방식은 alpha 크기와 위험 영향에 따라 단계화한다."** 🌟

### 3.2 5 Level 단계화 매트릭스

| Level | 조건 | 자본 반영 방식 |
|---|---|---|
| 🟢 **Level 0** | alpha 음수 + 신호 품질 弱 | 자본 반영 결정적 禁止 (Discard) |
| 🟡 **Level 1** | signal 良 + portfolio alpha 0 | Signal/Regime/Monitor 채택 (자본 직접 반영 아님) |
| 🟡 **Level 2** | alpha 0 근처 + 위험 중립 (Sharpe/MDD 악화 없음) | 🌟 **tie-breaker, ranking 보조, confidence tag** 형식 반영 |
| 🟡 **Level 3** | alpha 미세 양수 + Sharpe/MDD 중립 이상 | 🌟 **제한 cap (1~3% 보조 sleeve)** 또는 score 보정 |
| 🟢 **Level 4** | RULE 29 v2 通過 + Sharpe/MDD 개선 | 🌟 **정식 capital allocation** 후보 |
| 🟡 **Level 4-X** | alpha 양수 but MDD/Sharpe 악화 | 자본 반영 보류 + Signal Layer 채택 |

### 3.3 자본 반영 보류 정당화 사유 (alpha ≥ 0이라도 보류 가능)

| 사유 | 정당성 |
|---|---|
| 매매비용 (slippage/세금/회전율) 차감 후 음수 가능 | ✅ 정당 |
| MDD 악화 | ✅ 정당 |
| Sharpe 악화 | ✅ 정당 |
| 기존 자산 slot 박탈 (Sleeve 50/30/5 보호) | ✅ 정당 |
| 표본 부족 (N<30) | ✅ 정당 |
| 시기 편향 (특정 era만 양수) | ✅ 정당 |
| 단지 RULE 29 v2 完全 미통과만 | 🟡 약함 |
| 단지 portfolio alpha 0 만 | 🔴 **부족** (격언 #118 v3 위반) |

### 3.4 위반 처리

🚨 **"alpha ≥ 0인데 자본 반영 完全 차단"** 결정적 禁止 (정당 사유 없는 경우)

🚨 자본 반영 보류 시 사유 명시 의무

## §4. 🌟 격언 #120 v1 — Top5 Selection Feedback Bias 🌟 (신규 정식 정착)

### 4.1 본질

🌟 **"초기에 signal이 풍부한 자산은 Top5 참여 기회가 많아지고, 그 결과 더 많은 실측 자료와 후속 signal을 얻게 되어 자산 품질이 과대평가될 수 있다. 반대로 초기 signal이 부족하거나 Top5 rank가 낮은 자산은 실제 참여 기회가 적어 signal quality가 과소평가될 수 있다."** 🌟

### 4.2 부익부식 편향 구조

```
초기 signal 풍부 자산
→ Top5 진입 빈도 증가
→ 실제 매수/보유 데이터 증가
→ Phase B 자료 풍부
→ 더 많은 개선 후보 발견
→ 더 자주 채택 후보가 됨
🌟 (반복 강화) 🌟

vs.

초기 signal 부족 자산
→ Top5 진입 빈도 낮음
→ 실제 매수/보유 데이터 부족
→ Phase B 효과 0처럼 보임
→ 연구 우선순위 하락
→ 더 적은 signal 발굴
🚨 (반복 침몰) 🚨
```

### 4.3 의무 점검 항목 (모든 후보 보고 의무)

| # | 점검 항목 | 의미 |
|---|---|---|
| 1 | **signal ON 일수** | 신호 자체가 얼마나 자주 발생했나 |
| 2 | **실제 Top5 진입률** | 엔진이 실제로 살 기회를 줬나 |
| 3 | **평균 rank와 Top5 cut gap** | Top5 컷까지 얼마나 부족했나 |
| 4 | **shadow forward return** | 실제 매수와 무관하게 signal ON 후 종목 수익률 |
| 5 | **hit rate와 payoff 구조** | 예측력 + 비대칭 |
| 6 | **participation-adjusted signal score** | 참여 기회 보정된 점수 |
| 7 | **실제 portfolio alpha** | RULE 29 v2 차원 |
| 8 | **investability constraint** | Top5 진입 가능성 별도 |

### 4.4 결정적 입증 사례 — CAND-S121_β 역모멘텀
