🟢 진입 (기본)
· 설명: 칸 forward 60일 수익 − 종목 전체 평균(baseline), baseline 대비 유의성으로 신뢰가중
· 의미: 초록 = 평소보다 유리한 진입 / 빨강 = 불리 / 회색 = 평소 수준(edge≈0)
· 활용: "지금 이 거시 환경이 이 종목 진입에 유리한가" — 종목 자체 기준이라 종목 간 기본수익 차이를 제거, 진입 타이밍 판단에 최적
🟡 신뢰
· 설명: 칸 절대 수익을 통계 신뢰도(중첩 60일 보정 t-통계)로 축소
· 의미: 색 진함 = 신뢰할 강한 수익·손실 / 옅음 = 표본 적거나 산포 커 불확실
· 활용: 절대 수익 크기 + 신뢰도를 함께 볼 때. 적은 표본의 큰 평균을 걸러 과신 방지
⚪ 연속
· 설명: 칸 원본 forward 60일 평균수익 (가공 없음)
· 의미: 초록 = 절대수익 + / 빨강 = − (표본 무관 평균 그대로)
· 활용: 가공 전 원본 확인 · 다른 모드 비교 기준. 단 적은 표본 칸은 과신 위험
⬛ 영역
· 설명: 칸 수익 +면 초록 · ≤0이면 빨강으로 이분 (크기 무시)
· 의미: 방향만 — 수익/손실 영역 경계를 선명하게
· 활용: "어느 거시 영역이 수익 vs 손실인가" 큰 그림 · 경계선 파악
🟩 ARGUS
· 설명: ARGUS 엔진이 그 거시 구간에서 매긴 실제 진입 점수의 평균 (look-ahead 없음 · 신호+모멘텀 종합)
· 의미: 초록 = 엔진이 진입하려는 구간(양수) / 빨강 = 엔진이 회피하는 구간(음수, 약세 신호 우세) / 어두움 = 중립·게이트(0)
· 활용: "지도(과거 수익)와 엔진(실제 판단)이 일치하는가" 교차 점검. 단 슬롯경쟁·게이트 前 점수라 보유 확정은 아님

①시간축 차이 — 지도 셀 = 향후 60영업일 평균 수익. 브리핑 = 주간 리밸런싱 즉시 판단. 지도가 초록이어도 단기 하락 후 60일 뒤 회복하는 패턴 포함. ②매크로 축 차이 — 지도는 종목별 최고 IC 매크로를 자동 선택(예: SMH→WTI). 브리핑 시그널은 별도 임계값(예: TNX>4.0). 같은 종목이라도 다른 매크로를 볼 수 있음. ③Gate 미반영 — WTI>$90 셧다운 게이트 등 PRIMA 차단 규칙은 히트맵 색상에 반영되지 않음. 브리핑의 게이트 상태가 항상 우선. ④불일치 = 전환 단서 — 동일 BT 데이터 기반이므로, 지도 초록 + 브리핑 미진입 = 임박 시그널 후보. 지도 빨강 + 브리핑 보유 중 = 청산 시그널 주시. ⑤복합 Y 해석 — comp Y는 IC가중 직교화 잔차(σ 단위)로 직접 관측 불가. 방향만 참고 (Y축 라벨 화살표 ↑↓).

범례

⭐ = 현재 거시 좌표.
회색 슬레이트 = 데이터 부족(표본<8), 짙은 남색 = 중립(0%) — 구분됨.
평면 테두리·배지 색 = 신뢰도(녹/앰버/적).
색상 모드: 진입(기본) — 칸 수익 − 종목 평균(baseline) → 초록=평소보다 유리한 진입 구간, 빨강=불리 (baseline 대비 유의성 신뢰가중). 신뢰 — 절대 수익 신뢰가중. 연속 — 원본 평균수익. 영역 — 수익/손실 이분. ARGUS — 엔진이 매긴 실제 원점수(양수=진입 · 음수=회피 · look-ahead 없음 · 지도↔엔진 교차 점검).
격자 방식: 분위(기본) — 칸별 표본 균등·회색 최소·현재 지점 기대수익 정밀 / 축 거리 왜곡(칸 폭 불균등). 범위 — 축 거리·궤적 속도·경계까지 거리 정확·매크로 실제 형태(비선형 굴절) 보존 / 회색 칸 증가.
경계: 축을 forward IC로 선택 → in-sample 진단. 신호·자본 근거 아님.
